# مديري المالي الشخصي 💰

تطبيق ويب تقدمي (PWA) لإدارة الشؤون المالية الشخصية، مصمم خصيصاً للعمل على أجهزة الأندرويد مع دعم كامل للغة العربية (RTL).

## 📥 تحميل تطبيق الأندرويد (APK)

> **رابط التحميل المباشر:**
> https://github.com/aszxcvbn1578-cmyk/finance-tracker/releases/latest/download/finance-tracker.apk

### طريقة التثبيت على الجوال
1. افتح الرابط أعلاه من متصفح الجوال وحمّل ملف `finance-tracker.apk`
2. افتح الملف من مجلد التنزيلات
3. إذا ظهرت رسالة تحذير، اختر "السماح بالتثبيت من هذا المصدر"
4. اضغط "تثبيت" ✅

> يتم بناء ملف APK تلقائياً عبر GitHub Actions عند كل تحديث، ويمكنك أيضاً التثبيت كتطبيق ويب (PWA) مباشرة من المتصفح.


## المميزات

- ✅ **تتبع المعاملات**: إضافة وحذف الدخل والمصاريف بسهولة
- ✅ **فئات ذكية**: 12 تصنيفاً مع أيقونات وألوان مميزة
- ✅ **إدارة الميزانية**: تحديد ميزانيات شهرية لكل فئة مع تنبيهات بصرية
- ✅ **تقارير ورسوم بيانية**: مخطط دائري (Donut) لتوزيع المصاريف + ملخص شهري
- ✅ **العمل دون اتصال**: Service Worker مع تخزين مؤقت للعمل بلا إنترنت
- ✅ **تثبيت على الأندرويد**: PWA قابل للتثبيت على الشاشة الرئيسية
- ✅ **تصميم متجاوب**: يعمل على جميع أحجام الشاشات
- ✅ **الوضع الداكن**: دعم تلقائي للوضع الليلي
- ✅ **تخزين آمن**: جميع البيانات محفوظة محلياً على جهازك (localStorage)

## كيفية التثبيت والاستخدام

### التثبيت من GitHub عبر Pinokio
1. في Pinokio، افتح تبويب **Download** من الشريط الجانبي
2. الصق رابط المستودع:
   ```
   https://github.com/aszxcvbn1578-cmyk/finance-tracker
   ```
3. اضغط **Download** وسيتم تثبيت التطبيق تلقائياً

### التشغيل عبر Pinokio
1. افتح Pinokio وابحث عن "مديري المالي الشخصي" في تبويب API
2. اضغط عليه لفتح التطبيق

### التثبيت على أندرويد (PWA)
1. افتح التطبيق في متصفح Chrome على جهاز الأندرويد
2. اضغط على ⋮ (القائمة) في الأعلى
3. اختر "إضافة إلى الشاشة الرئيسية" أو "تثبيت التطبيق"
4. سيظهر التطبيق كأيقونة على جهازك ويعمل كتطبيق مستقل

### الاستخدام اليومي
1. **إضافة معاملة**: اضغط على زر "+" في أسفل يسار الشاشة
2. **تحديد النوع**: اختر مصروف (أحمر) أو دخل (أخضر)
3. **اختيار الفئة**: حدد التصنيف المناسب من الشبكة
4. **التقارير**: انتقل لتبويب التقارير لعرض الرسم الدائري والملخص

## واجهة برمجة التطبيقات (API)

جميع البيانات محفوظة في `localStorage` ويمكن الوصول إليها برمجياً.

### JavaScript

```javascript
// قراءة البيانات
const transactions = JSON.parse(localStorage.getItem('finance_transactions') || '[]');
const categories = JSON.parse(localStorage.getItem('finance_categories') || '[]');
const budgets = JSON.parse(localStorage.getItem('finance_budgets') || '[]');

// حساب الرصيد
const balance = transactions.reduce(
  (sum, t) => sum + (t.type === 'income' ? t.amount : -t.amount), 0
);

// إضافة معاملة (يدعم الدوال الجاهزة في التطبيق)
addTransaction('expense', 150.5, 'food', 'غداء', new Date().toISOString());

// حذف معاملة
deleteTransaction(ID);
```

### بنية المعاملة

```json
{
  "id": 1792285831040,

  "amount": 250.5,
  "category": "food",
  "note": "بقالة",

}
```
